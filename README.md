# ZEAM :: Pass

Let agents into your service. Charge per call, admit listed keys, or both, over MCP and x402 HTTP on Base.
No sign-up and no API key for the agent.

- `node/`: `@zeam-labs/pass` on npm (Node 18+)
- `python/`: `zeam-pass` on PyPI (Python 3.9+)
- `wordpress/zeam-pass/`: the WordPress plugin; its `lib/src/` is the reference engine
- `docs/SELL.md`: selling with Pass
- `docs/AGENTS.md`: paying a Pass seller as an agent
- `docs/ENGINE.md`: the engine and its constants

The seller keeps 90.01% of every sale; 9.99% goes to ZEAM. A gate's first 10,000 checks a month are free.
